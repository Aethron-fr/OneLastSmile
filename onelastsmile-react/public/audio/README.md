# Mood Music Audio Files

Place your MP3 files here with these exact filenames:

| File | Mood | When it plays |
|------|------|---------------|
| `mood-apology.mp3` | Soft, melancholic, sparse piano | Opening Screen 1 (Sorry, Anushka) |
| `mood-precious.mp3` | Warm, tender, gentle acoustic | Opening Screen 2 (The handmade gift) |
| `mood-importance.mp3` | Slow emotional build, strings/pads | Opening Screen 3 (How important she is) |
| `mood-joke.mp3` | Light, playful, upbeat pluck/ukulele | Opening Screen 4 (Lighthearted joke) |
| `mood-wish.mp3` | Grand, warm, uplifting — peak moment | Opening Screen 5 (Birthday wish) |
| `mood-warning.mp3` | Quiet, anticipatory, minimal | Opening Screen 6 (One-time warning) |
| `mood-nostalgic.mp3` | Tender, nostalgic | Main site sections |
| `mood-confession.mp3` | Intense, vulnerable | Confession/proposal sections |
| `mood-hopeful.mp3` | Hopeful, warm resolution | Keep This Story ending |
| `mood-fading.mp3` | Somber, fading — plays once, no loop | Let It Fade Away ending |

All files are served from `/audio/` — the system crossfades between them automatically.
If a file is missing, that mood is silently skipped (no errors).
